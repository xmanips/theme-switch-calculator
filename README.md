# Theme Switch Calculator

Une calculatrice interactive développée avec HTML, CSS et JavaScript, proposant trois thèmes visuels.

## Présentation du projet

Theme Switch Calculator est un projet personnel réalisé à partir d'un défi proposé par [Frontend Mentor](https://www.frontendmentor.io/).

L'objectif était de concevoir une calculatrice fonctionnelle tout en mettant en pratique les fondamentaux du développement front-end.

L'application permet d'effectuer des opérations arithmétiques et de personnaliser son apparence grâce à trois thèmes différents.

## Fonctionnalités

- Effectuer des opérations arithmétiques :
  - Addition (+)
  - Soustraction (-)
  - Multiplication (×)
  - Division (/)
- Choisir entre trois thèmes visuels.
- Supprimer le dernier caractère avec le bouton DEL.
- Effacer l'affichage avec le bouton RESET.
- Effectuer des calculs comportant plusieurs nombres et opérateurs.
- Gérer les erreurs de calcul.
- Profiter d'une interface adaptée aux petits écrans.

## Technologies utilisées

- **HTML5** : structure de l'application.
- **CSS3** : mise en forme, Flexbox, CSS Grid, variables CSS et media queries.
- **JavaScript** : logique de calcul, manipulation du DOM et gestion des interactions.

## Ce que j'ai appris

La réalisation de ce projet m'a permis de pratiquer plusieurs notions :

- La sélection et la manipulation des éléments HTML avec JavaScript.
- La gestion des événements avec `addEventListener()`.
- L'utilisation des fonctions et des variables.
- Les conditions et les valeurs booléennes.
- La gestion des erreurs avec `try...catch`.
- La manipulation des chaînes de caractères.
- L'utilisation des variables CSS pour créer plusieurs thèmes.
- La création d'interfaces adaptatives avec Flexbox, CSS Grid et les media queries.

## Lancer le projet

1. Cloner ce dépôt sur votre ordinateur :

   ```bash
   git clone URL_DE_VOTRE_DEPOT
   ```

2. Accéder au dossier du projet :

   ```bash
   cd theme-switch-calculator
   ```

3. Ouvrir le fichier `index.html` dans votre navigateur web.

Aucune installation supplémentaire n'est nécessaire.
